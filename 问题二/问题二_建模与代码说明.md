# 问题二建模与代码说明

## 1. 用什么模型

问题二当前使用的是“对数衰减回归 + 类型交互项”的统计归因模型。

设

`Y = ln(M0 / Mt)`

则主模型写为：

```text
Y = β0
  + β1*I(小号铁钉)
  + β2*I(小号铁夹)
  + β3*I(锈蚀钢筋)
  + β4*time_z
  + β5*time_z^2
  + β6*cum_temp_z
  + β7*cum_hum_z
  + β8*cum_th_z
  + β9*I(锈蚀钢筋)*time_z
  + β10*I(小号铁钉)*time_z
  + β11*I(小号铁夹)*time_z
  + ε
```

其中：

- `time_z`：标准化时间
- `cum_temp_z`：累计温度标准化值
- `cum_hum_z`：累计湿度标准化值
- `cum_th_z`：累计温湿交互标准化值
- 普通钢筋为基准组

代码里同时做了三种版本对照：

- 无交互
- 对称交互
- 门槛交互

并额外跑了 `ridge` 作为稳定性补救。

## 2. 这套模型的优点

- 可解释，能直接回答题目中的主效应和交互效应
- 能区分不同材料类型的时间敏感性
- 能把环境暴露和锈蚀效应放进同一回归框架
- 适合写论文中的统计结论表

## 3. 主要缺点

1. 共线性明显。
   `time_z`、`time_z^2`、累计温度、累计湿度在单一天气轨迹下高度相关，系数容易不稳。

2. 不是严格因果识别。
   所有样品共享同一条天气轨迹，所以能做的是统计归因，不宜写成强因果。

3. 交互增益不稳定。
   总体 CV 上门槛交互未必总是最优，但在锈蚀钢筋和长延迟窗口上更有用。

4. 重复测量独立性有限。
   同一样品跨天观测存在序列相关，OLS 只能作为主解释模型。

## 4. 怎么补救

- 保留 OLS 作为正文主模型，方便解释系数和显著性。
- 增加共线性诊断，明确指出变量相关很高。
- 用 ridge 作为稳健性补救，检查系数符号和大小是否稳定。
- 对问题二结论采用“统计关联 + 工程增益”的措辞，不写强机理因果。
- 在正文中重点强调锈蚀钢筋与 22-90 天窗口的局部改进，而不是宣称所有指标全局最优。

## 5. 现有结果说明

当前输出已经证明：

- 时间主效应显著
- 温度累计项显著
- 湿度累计项显著
- 温湿交互项显著
- 锈蚀钢筋×时间项显著
- 门槛交互在锈蚀钢筋 22-90 天窗口有改善
- ridge 后系数符号基本不变，说明主结论稳定

但同时也要承认：

- 总体 CV 上，门槛交互未必全面优于无交互版本
- 因此它更适合被写成“局部增益型创新”，而不是“全局最优模型”
