# 图表需求与数据来源说明

## 1. 文档用途

本文档用于统一三件事：

1. 每张图需要哪些数据。
2. 这些数据来自哪里、在哪一步生成。
3. 每张图最终要达到什么目的。

图表主责为 `C_论文与图表负责人`，`B_代码与实验负责人` 提供数据和脚本，`A_建模负责人` 负责确认公式口径与统计口径。

---

## 2. 总原则

1. 每张图只表达一个核心结论。
2. 图表必须能追溯到原始数据或可复现的中间结果。
3. 正文图优先，附录图只保留诊断性或补充性内容。
4. 图中的数字必须与正文、代码输出和 Excel 结果一致。
5. 图表风格统一，避免多套配色、坐标和术语混用。

## 4. 每张图要什么数据、要表达什么

### 图1 四类样品原始剩磁衰减曲线

**需要的数据**
- 样品类型
- 样品编号
- 天数
- 剩磁观测值
- 锈蚀属性

**数据来源**
- `原始数据/附件1_模拟实验数据.csv`

**图表目的**
- 先把原始现象展示清楚。
- 看出四类样品衰减快慢不同。
- 看出同类样品之间的离散程度。

**推荐形式**
- 同图四条主折线。
- 每类样品一种颜色。
- 点较多时可叠加半透明散点。

### 图2 四类样品归一化曲线叠加图

**需要的数据**
- 第0天初值 `M(0)`
- 每天剩磁 `M(t)`
- 归一化保留率 `R_s(t)=M(t)/M(0)`

- `原始数据/附件1_模拟实验数据.csv`
- B 计算后的归一化底表

**图表目的**
- 证明归一化后同类型样品高度重合。
- 支持“初值分离 + 类型共享衰减函数”的主线。

**推荐形式**
- 叠加折线图。
- 同类样品同色，均值线加粗。
- 可加 95% 置信带。

### 图3 `M0` 与 `M90/M0` 散点图

**需要的数据**
- 第0天初值 `M0`
- 第90天剩磁 `M90`
- 第90天归一化值 `M90/M0`

**数据来源**
- `原始数据/附件1_模拟实验数据.csv`
- 第0天、第90天派生表

**图表目的**
- 检验初值与长期归一化保留率是否存在强相关。
- 支持“初值与衰减机制可近似分离”的建模假设。

**推荐形式**
- 散点图。
- 加线性拟合线或 LOESS 线。
- 标注相关系数。

### 图4 公共核假设检验结果表

**需要的数据**
- 共享核模型拟合指标
- 单样品独立拟合模型拟合指标
- AIC、BIC、F 检验、似然比检验统计量

**数据来源**
- `结果输出/公共/模型参数与检验.csv`

**图表目的**
- 说明共享公共衰减函数是否显著恶化拟合。
- 给出“共享核是否合理”的统计依据。

**推荐形式**
- 正文放表格。
- 必要时附一个条形对比小图。

### 图5 问题2系数表 + 消融对比图

**需要的数据**
- 时间、温度、湿度主效应系数
- 温度×湿度交互项系数
- 时间×锈蚀交互项系数
- 标准误、t 值、p 值
- 偏 `R^2` 或效应量
- 无交互、对称交互、门槛交互三种版本的 CV-RMSE 和 MAE

**数据来源**
- `结果输出/问题二/问题2_主效应与交互效应.csv`
- `结果输出/问题二/问题2_消融分析.csv`
- `结果输出/问题二/问题2_交叉验证.csv`

**图表目的**
- 回答问题2里的主效应和交互效应。
- 同时展示门槛型交互在工程预测上的改善。

**推荐形式**
- 上半部分用系数表或系数森林图。
- 下半部分用误差对比柱图或折线图。

### 图6 1-90 天动态阈值曲线图

**需要的数据**
- 类型共享保留率 `R_s(t)`
- 国标阈值 `Θ_s^GB`
- 动态阈值 `Θ_s(t)=Θ_s^{GB}·R_s(t)`

**数据来源**
- `结果输出/问题三/问题3_动态阈值修正表.xlsx`
- 阈值生成脚本

**图表目的**
- 展示国标阈值如何映射到不同延迟天数。
- 为问题3提供 1-90 天完整输出。

**推荐形式**
- 多折线图。
- 横轴为天数，纵轴为阈值。
- 可用虚线表示国标静态阈值基准。

### 图7 反推初值区间宽度-延迟天数曲线

**需要的数据**
- Bootstrap 反推初值区间下界 `M0^L`
- Bootstrap 反推初值区间上界 `M0^U`
- 区间宽度
- 延迟天数
- 灰区标记

**数据来源**
- `结果输出/问题四/问题4_三区域判定结果.csv`
- Bootstrap 输出结果

**图表目的**
- 展示延迟越长，不确定性越大。
- 给出灰区与长延迟失效的判定依据。

**推荐形式**
- 折线图 + 阴影带。
- 或区间宽度散点图。

### 图8 现场判定流程图

**需要的数据**
- 样品类型
- 延迟天数
- 天气轨迹
- 实测剩磁
- 动态阈值
- Bootstrap 区间

**数据来源**
- 全部核心结果汇总

**图表目的**
- 展示问题4从输入到输出的完整闭环。
- 让答辩时的流程解释更直观。

**推荐形式**
- 标准流程图。
- 方框加箭头。
