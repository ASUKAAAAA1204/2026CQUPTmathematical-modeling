# B题论文正式章节草稿

## 1. 结构发现与建模思路

对附件 1 的实验数据进行整理后可以发现，四类样品虽然在第 0 天的初始剩磁水平存在明显差异，但在以第 0 天观测值为基准进行归一化后，同类型样品的剩磁保留率曲线高度一致。这说明样品间的个体差异主要体现在初始剩磁水平，而衰减规律主要由样品类型及外部环境共同决定。基于这一发现，本文不再对每个样品分别建立完全独立的衰减曲线，而是采用“个体初值锚定 + 类型平均衰减函数”的统一建模思路，将剩磁衰减写成个体初值与类型平均衰减函数的乘法分解形式。

设第 \(i\) 个、类型为 \(s\) 的样品在第 \(t\) 天测得的剩磁为 \(M_{i,s}(t)\)，其第 0 天初始剩磁为 \(M_{i,s}(0)\)。定义类型 \(s\) 在第 \(t\) 天的共享保留率函数为 \(R_s(t)\)，则有

\[
M_{i,s}(t)=M_{i,s}(0)\cdot R_s(t).
\]

这一结构有三点优势。第一，它保留了第 0 天观测值在问题中的物理含义，使个体差异不再被错误地混入衰减机制。第二，它允许四类样品在统一框架下比较稳定性差异。第三，它为问题 3 和问题 4 中的动态阈值修正、反推初值和工程判定提供了直接数学接口。因此，本文后续所有问题均围绕类型平均衰减函数 \(R_s(t)\) 展开。

进一步地，为验证这种“个体初值 × 类型平均衰减函数”的结构是否合理，本文设置两类地基检验。第一类检验考察初始剩磁与长期归一化保留率之间的相关性，即分别计算

\[
\mathrm{corr}\!\left(M_{i,s}(0),\frac{M_{i,s}(90)}{M_{i,s}(0)}\right).
\]

若不存在明显强相关反证，则说明“初值大小”与“归一化衰减规律”可以近似分离。第二类检验比较“同类样品共享平均衰减函数”与“每个样品单独拟合归一化曲线”两种结构，通过 AIC、BIC 或似然比检验判断共享平均函数是否显著恶化拟合性能。若共享平均函数并未显著降低模型表现，则说明采用“类型平均衰减函数 + 个体初值”的结构是合理且简洁的。

在上述结构识别基础上，本文将剩磁衰减建模为一种经验衰减过程：时间项刻画自然退磁趋势，环境累计项刻画相对该趋势的经验修正。由于当前数据仅覆盖一条天气轨迹，因此本文不把环境系数解释为严格独立因果作用，而是将其视为该天气轨迹下的统计关联和工程修正量。

## 2. 统一衰减模型与环境交互项

为刻画剩磁衰减随时间和环境的变化，本文在归一化后对对数保留率建模。设

\[
R_{i,s}(t)=\frac{M_{i,s}(t)}{M_{i,s}(0)},
\]

定义累计环境量：

\[
A_T(t)=\sum_{d=1}^{t}(T_d-\bar T),\qquad
A_H(t)=\sum_{d=1}^{t}(H_d-\bar H),
\]

并定义门槛型高温高湿交互项：

\[
A_{TH}(t)=\sum_{d=1}^{t}\max(T_d-T^*,0)\max(H_d-H^*,0),
\]

其中 \(T_d,H_d\) 分别为第 \(d\) 天的气温和相对湿度，\(\bar T,\bar H\) 为样本期平均温湿度，\(T^*,H^*\) 为门槛值。主模型写为

\[
\ln R_s(t)=-(a_st+\beta_sA_T(t)+\gamma_sA_H(t)+\delta_sA_{TH}(t)).
\]

于是对任意样品有

\[
M_{i,s}(t)=M_{i,s}(0)\cdot
\exp\!\Big(-(a_st+\beta_sA_T(t)+\gamma_sA_H(t)+\delta_sA_{TH}(t))\Big).
\]

该模型的优势在于：一方面保留了“个体初值 × 类型共享保留率函数”的清晰结构，另一方面通过门槛型交互项引入了适度创新。这里的创新不是试图建立完整机理，而是识别“高温高湿风险窗口”是否会对剩磁退化产生额外放大作用。

门槛值的设置采用双层方案。正文主模型中取

\[
T^*=\bar T,\qquad H^*=\bar H,
\]

反映本实验天气轨迹内部的相对高风险区；稳健性分析中再引入固定物理门槛

\[
T^*=25^\circ C,\qquad H^*=75\%,
\]

作为补充对照。

需要强调的是，虽然 \(A_T,A_H,A_{TH}\) 采用原始量纲定义以保留物理解释性，但在参数估计过程中，所有自变量先进行标准化后再进入回归或岭回归估计，以避免特征尺度差异导致的惩罚失真。这一点必须在正文中明确写出，以保证文档与程序实现一致。

作为对照，本文还保留一个更简单的纯时间指数模型

\[
R_s(t)=\exp(-a_st),
\]

以及不含交互项的累计环境模型

\[
\ln R_s(t)=-(a_st+\beta_sA_T(t)+\gamma_sA_H(t)).
\]

它们用于辅助检验门槛型交互项是否确实带来稳定的预测增益。

## 3. 问题一：初值验证与第 23-29 天预测

问题一包含两层任务：其一是验证不同类型样品的初始剩磁基准特征，其二是建立能够外推到任意给定时点的剩磁预测模型。对第一层任务，本文分个体层和类型层处理。个体层面直接使用每个样品的第 0 天实测值 \(M_{i,s}(0)\) 作为初值锚点；类型层面则分别报告四类样品第 0 天的均值、标准差与 95% 置信区间，以回答题目中“不同类型样品初始剩磁基准值”的要求。

为了使“初值分离”不是经验直觉而是真正的结构结论，本文在问题一中显式加入两项检验。第一项是“初值独立性”检验，即考察第 0 天初值与第 90 天归一化保留率之间是否存在明显强相关。若仅观察到弱相关或无稳定模式，则说明类型平均衰减函数假设没有被数据直接否定。第二项是“共享平均函数合理性”检验，即比较共享平均衰减函数模型与逐样品独立归一化拟合模型的相对优劣。若共享平均函数并未显著恶化拟合指标，则可认为“类型平均衰减函数 + 个体初值”的结构在统计上是可接受的。

在上述验证通过后，问题一中的预测任务便可统一交由主模型完成。对于任意给定天数 \(t\)，预测公式为

\[
\hat M_{i,s}(t)=M_{i,s}(0)\cdot \hat R_s(t).
\]

若需要给出某一类型的代表性预测结果，只需将该类样品的第 0 天均值 \(\bar M_s(0)\) 代入，即得

\[
\hat M_{s,\mathrm{mean}}(t)=\bar M_s(0)\cdot \hat R_s(t).
\]

因此，第 23-29 天的所有预测值均由统一衰减模型直接给出，而不是依赖插值、局部光滑或单独构造的过渡公式。这一点对论文自洽性至关重要，因为它保证了问题一的数值结果和后续问题三、问题四中的判定线及反推公式来源一致。

正式论文中，问题一应至少给出四类结果：第 0 天统计表、初值独立性检验结果、共享平均函数假设检验结果，以及第 23-29 天的预测表。若篇幅允许，还应给出按样品编号展开的单样品预测区间，以更完整地展示模型的外推能力。

## 4. 问题二：独立贡献与交互效应分析

问题二是整篇论文中最容易被质疑的部分，因此必须回到题目规定动作。本文不再把重点放在“不同模型谁更先进”上，而是首先回答时间、温度、湿度及交互项各自的统计贡献，然后再用消融实验补充其工程意义。

为此，本文建议对归一化后的对数保留率建立规范的回归分析模型。例如可写为

\[
\ln R_{i,s}(t)
=
\alpha_0+\alpha_1 t+\alpha_2 T_t+\alpha_3 H_t+\alpha_4(T_tH_t)+\alpha_5(t\cdot Rust_s)+u_s+\varepsilon_{i,s,t},
\]

其中 \(Rust_s\) 为锈蚀指示变量，\(u_s\) 表示类型层面的分组效应。若直接使用累计量形式更稳定，也可改写为

\[
\ln R_{i,s}(t)
=
\alpha_0+\alpha_1 t+\alpha_2 A_T(t)+\alpha_3 A_H(t)+\alpha_4A_{TH}(t)+\alpha_5(t\cdot Rust_s)+u_s+\varepsilon_{i,s,t}.
\]

无论采用哪一种具体写法，问题二主文都必须报告以下统计量：

- 回归系数；
- 标准误；
- t 值或 z 值；
- p 值；
- 效应量或偏 \(R^2\)；
- 交互项方向和大小。

这样才能正面回答“独立贡献与交互效应”这一题目要求。

在完成标准统计归因之后，本文再补充一个工程化消融实验，比较三种交互构造：

1. 无交互项；
2. 对称交互项 \((T-\bar T)(H-\bar H)\)；
3. 门槛型交互项 \(\max(T-T^*,0)\max(H-H^*,0)\)。

这里的目的不是替代统计显著性分析，而是验证交互项是否真正带来预测增益。为此需要报告：

- 分块交叉验证误差；
- 各样品类型的预测误差；
- 锈蚀钢筋在第 22-90 天区间上的误差改善比例。

因此，问题二的推荐结论写法应为：时间项刻画基础自然退磁趋势；温度和湿度主效应对衰减有显著修正作用；温度 × 湿度交互项在高温高湿区间内表现出更强的退磁放大效应；时间 × 锈蚀交互项说明锈蚀钢筋对长期衰减更敏感；而门槛型交互项在锈蚀钢筋上的预测表现优于无交互和对称交互方案。这样便同时完成了题目要求的“归因”与本文自身的“适度创新”。

## 5. 问题三：动态阈值修正表及其解释

问题三必须回到题面规定动作，即明确给出 1-90 天动态阈值修正表。设国标静态阈值为 \(\Theta_s^{GB}\)，则定义第 \(t\) 天的动态判定阈值为

\[
\Theta_s(t)=\Theta_s^{GB}\cdot R_s(t).
\]

其中，

\[
\Theta_s^{GB}=
\begin{cases}
1.0,& s\in\{\text{小号铁钉, 小号铁夹}\}\\
1.5,& s\in\{\text{普通钢筋, 锈蚀钢筋}\}
\end{cases}
\]

这一公式意味着：若某类样品在第 0 天刚好达到国标阈值，则在第 \(t\) 天经过衰减后，对应的现场判定线应为 \(\Theta_s(t)\)。因此，问题三的核心输出不是抽象概念，而是能够按天查询的动态阈值表。

建议提交的 Excel 附件至少包含以下列：

- 天数；
- 天气；
- 气温；
- 湿度；
- 四类样品保留率 \(R_s(t)\)；
- 四类样品动态阈值 \(\Theta_s(t)\)；
- 四类样品类型均值预测剩磁。

“反推初值”可以保留，但只作为问题三的补充解释工具。对现场实测剩磁 \(M_{obs}\)，定义

\[
\hat M_0=\frac{M_{obs}}{R_s(t)}.
\]

这表示当前实测值若被推回第 0 天，对应的等效初始剩磁水平。它与动态阈值表是等价的另一种解释方式，而不是问题三的替代任务。

因此，论文中应明确强调：本文并没有修改国标阈值本身，而是根据衰减模型把国标静态阈值映射为观测时点的动态判定线。

## 6. 问题四：雷击判定流程与置信度评估

问题四应严格按题目要求组织为四个环节：数据预处理、衰减预测、动态阈值调整、结果置信度评估。

首先是数据预处理模块。当前方案中应补齐以下内容：

- 异常值检测；
- 缺失值填补；
- 单位检查；
- 样品类型核验；
- 延迟天数与天气轨迹匹配检查。

其次是衰减预测模块。输入样品类型、延迟天数、天气轨迹和实测剩磁后，模型输出对应的保留率 \(R_s(t)\) 或预测剩磁 \(\hat M_{i,s}(t)\)。

第三步是动态阈值调整，即依据问题三中的阈值表或公式计算

\[
\Theta_s(t)=\Theta_s^{GB}\cdot R_s(t).
\]

第四步是结果置信度评估。本文保留成熟的 block bootstrap 三区域工程判定思路。对现场样品先计算反推初值

\[
\hat M_0=\frac{M_{obs}}{R_s(t)},
\]

再利用按样品编号分层的 cluster block bootstrap 获得其区间

\[
[\hat M_0^L,\hat M_0^U].
\]

据此定义三区域判定：

- 若 \(\hat M_0^L\ge \Theta_s^{GB}\)，判为“支持曾遭雷击”；
- 若 \(\hat M_0^U< \Theta_s^{GB}\)，判为“不支持曾遭雷击”；
- 其余情况判为“灰区/证据不足”。

在三区域规则之外，仍可输出辅助概率

\[
P(\text{雷击})=
1-\Phi\left(
\frac{\Theta_s^{GB}-\hat M_0}{SE(\hat M_0)}
\right),
\]

但主结论仍以三区域判定为准。

对于长延迟场景，本文不再单独包装“证据寿命”概念，而是采用更稳妥的工程表述：当延迟天数较大，或反推初值区间的相对宽度

\[
\frac{\hat M_0^U-\hat M_0^L}{\hat M_0}
\]

超过预设阈值时，判定自动进入灰区，并建议结合其他证据或进行复检。这样便能自然地处理长延迟失效问题，而不必引入支撑不足的新概念。

最后，问题四建议绘制一张现场判定流程图：输入样品类型、延迟天数、天气轨迹与实测剩磁；计算 \(R_s(t)\)；反推 \(\hat M_0\)；生成区间 \([\hat M_0^L,\hat M_0^U]\)；输出“支持/灰区/不支持”结论；若落入灰区，则建议复检或补充其他证据。该流程图会显著增强论文的工程落地感。

## 7. 参数估计、交叉验证与区间估计

在统计实现上，本文建议采用分层估计框架。主模型可使用岭回归、GLS 或混合效应回归实现，自变量在进入估计前统一标准化，以避免不同尺度特征带来的数值失真。由于时间项与环境累计项高度相关，因此参数解释以稳健预测和统计关联为主，而不作强因果外推。

模型验证采用时间块交叉验证，以避免同一时间段内的信息泄漏。验证时应比较纯时间模型、含环境主效应模型、含门槛交互项模型以及不含交互项的消融模型，并统一报告 CV-RMSE、MAE 以及按样品类型分层的预测误差，特别关注锈蚀钢筋在中长期时段的表现差异。

区间估计采用按样品编号分层的 cluster block bootstrap：每次重抽样保留同一样品的完整时间序列，并重新估计模型参数，以获得预测值、动态阈值和反推初值的区间估计。正式论文中应明确写出重抽样次数不少于 1000，区间类型采用 percentile 或 BCa。同时，还应主动声明：当前 Bootstrap 区间主要反映样品层面的不确定性，尚未完全覆盖跨年份、跨地区天气变化带来的外推风险。

## 8. 论文结构与创新点

在上述统一框架下，整篇论文建议采用如下结构：第一部分介绍题意与数据；第二部分给出初值分离与共享平均函数假设；第三部分建立统一衰减模型；第四部分完成问题一中的初值验证与第 23-29 天预测；第五部分按照题面要求完成问题二中的独立贡献与交互效应分析；第六部分构造问题三中的 1-90 天动态阈值表；第七部分给出问题四中的三区域判定流程；第八部分展示模型验证、Bootstrap 区间估计与边界声明；最后总结应用价值与推广边界。

创新点建议集中表述为四条。第一，识别并验证了“个体初值 × 类型平均衰减函数”的乘法结构。第二，在问题三中，将国标静态阈值映射为观测时点的动态判定线，并给出 1-90 天阈值表。第三，在问题二中引入门槛型高温高湿交互项，并通过消融实验验证其对锈蚀钢筋预测的改善作用。第四，在问题四中构建了基于 block bootstrap 的三区域工程判定流程。这样的创新叙事强度适中、证据充分，更符合竞赛评审偏好。
