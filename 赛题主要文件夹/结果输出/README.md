# 结果输出目录说明

本目录保存 B 题的中间结果、最终结果与复现脚本输出。当前脚本以 `solve_b.py` 为唯一主入口，所有表格均由同一套原始附件数据生成。

## 目录结构

- `solve_b.py`：主求解脚本
- `generate_figures.py`：图表生成脚本
- `B题_完整求解报告.md`：Markdown 兜底报告
- `B题_完整求解报告.docx`：历史 Word 报告
- `公共/`：跨问题共享输出
- `问题一/`：问题1输出
- `问题二/`：问题2输出
- `问题三/`：问题3输出
- `问题四/`：问题4输出
- `figures/`：正文图表
