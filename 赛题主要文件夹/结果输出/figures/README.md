# 图表目录

本目录保存由 `generate_figures.py` 生成的 SVG 图表。图表清单、所需数据和图表目的以 `..\..\图表需求与数据来源说明.md` 为准。

## 图表清单

| 文件名 | 图表名称 | 主要数据 | 图表目的 |
|---|---|---|---|
| `fig1_raw_decay.svg` | 四类样品原始剩磁衰减曲线 | 样品类型、样品编号、天数、剩磁观测值、锈蚀属性 | 展示原始衰减轨迹和类型差异 |
| `fig2_normalized_overlay.svg` | 四类样品归一化曲线叠加图 | 第0天初值、每日剩磁、归一化保留率 | 证明初值分离与类型共享衰减函数 |
| `fig3_m0_vs_m90_ratio.svg` | `M0` 与 `M90/M0` 散点图 | 第0天初值、第90天剩磁、归一化值 | 检验初值与长期保留率的相关性 |
| `fig4_problem2_coefficients.svg` | 问题2主效应与交互效应系数图 | 系数、标准误、t 值、p 值、效应量 | 回答问题2的统计归因 |
| `fig5_problem2_ablation.svg` | 问题2三种交互构造消融对比图 | CV-RMSE、MAE、三类交互版本结果 | 展示门槛型交互的工程改善 |
| `fig6_dynamic_thresholds.svg` | 1-90 天动态阈值曲线图 | `R_s(t)`、国标阈值、动态阈值表 | 展示问题3的阈值映射结果 |
| `fig7_interval_width_delay.svg` | 反推初值区间宽度-延迟天数曲线图 | Bootstrap 区间、区间宽度、延迟天数 | 支撑问题4灰区与失效规则 |
| `fig8_flowchart.svg` | 现场判定流程图 | 输入字段、判定规则、Bootstrap 区间 | 展示问题4工程闭环 |

## 使用说明

- 图1、图2、图3可在数据清洗后直接生成。
- 图4、图5应与问题2最新版结果同步。
- 图6必须与问题3最新版阈值表同步。
- 图7、图8必须与问题4最新版输出同步。
