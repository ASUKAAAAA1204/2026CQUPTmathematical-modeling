# 问题三方法规划

## 1. 目标

问题三的目标不是“把阈值改小”，而是把国标静态阈值映射到给定延迟天数和天气轨迹下的观测时点，形成可查表、可解释、可答辩的动态判定线。

核心表达：

```text
Theta_s(t) = Theta_s^GB * R_s(t)
M0_hat = M_obs / R_s(t)
```

两者等价，前者适合出表，后者适合解释。

## 3. 推荐最终口径

正文建议统一写成：

> 本文不改变国标阈值本身，而是将其通过类型保留率函数映射到现场观测时点，得到时点等效观测判定线。

并明确：

- 不写“阈值衰减”
- 不写“阈值变小”
- 不写“阈值随时间降低”

只写：

- `动态判定阈值`
- `时点等效观测判定线`
- `反推初值判定`

## 4. 方法设计

### 4.1 输入

- 样品类型
- 延迟天数
- 天气轨迹
- 类型保留率函数 `R_s(t)`

### 4.2 输出

- 该时点的等效观测阈值 `Theta_s(t)`
- 该时点的类型预测剩磁
- 可选：反推初值下的判断结果

### 4.3 判定逻辑

```text
若 M_obs >= Theta_s(t)，则观测值满足该时点要求
若 M0_hat >= Theta_s^GB，则等价地满足国标初值要求
```

## 7. 风险边界

需要避免的错误写法：

- 把动态阈值当成新的国标
- 把反推初值当成独立新模型
- 把等效映射写成强因果机制

正确定位是：

> 工程映射 + 判定辅助 + 可查表输出
