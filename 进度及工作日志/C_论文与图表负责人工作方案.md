# C_论文与图表负责人工作方案

## 0. 配套文档

与 C 直接相关的执行文档统一为：

- [论文手工作内容.md](../赛题主要文件夹/论文手工作内容.md)
- [图表手工作内容.md](../赛题主要文件夹/图表手工作内容.md)
- [图表需求与数据来源说明.md](../赛题主要文件夹/图表需求与数据来源说明.md)

其中：

- `论文手工作内容.md` 负责正文、结果整合、答辩表达
- `图表手工作内容.md` 负责正文图、附录图、图表同步
- `图表需求与数据来源说明.md` 负责图表数据来源、图表目的和交付形式

后续不再单独维护“工作流程”版本文档。

## 1. 角色定位

C 负责项目的论文表达、图表生产、结果解释、创新点表述、边界声明与答辩口径统一。C 的核心任务不是发明新模型，而是把 A 的数学口径和 B 的结果输出整合成一篇：

- 可提交
- 可阅读
- 可答辩
- 不夸大
- 图表完整

的竞赛论文。

本次调整后，`图表主责归 C`。B 提供图表数据和脚本，C 负责最终绘图、样式、版式、图注与嵌入。

---

## 2. 总体职责

### 2.1 论文职责

C 负责：

- 全文目录与章节组织
- 正文撰写
- 摘要、结论、创新点、局限性
- 图表嵌入与图注
- 术语统一
- 答辩提纲

### 2.2 图表职责

C 负责：

- 选图
- 作图
- 图表版式统一
- 图题与图注撰写
- 图表在论文中的位置安排
- 图表与正文的逻辑衔接

### 2.3 答辩职责

C 负责：

- 提炼答辩主线
- 统一三人的答辩口径
- 整理高频问题与标准回答

---

## 3. 论文层任务细化

## 3.1 目录与结构

C 必须将论文结构固定为与题面四问完全一致的形式：

1. 题意与数据说明
2. 结构发现：初值分离与共享平均衰减函数
3. 统一衰减模型
4. 问题 1：初值验证与 23-29 天预测
5. 问题 2：独立贡献与交互效应分析
6. 问题 3：动态阈值修正表
7. 问题 4：雷击判定流程与置信度评估
8. 模型验证、局限性与边界声明
9. 结论与应用建议

C 要防止论文结构再次被“概念框架”带偏。

## 3.2 正文写作任务

C 负责逐章写作：

- 问题重述
- 数据说明
- 建模假设
- 结构发现
- 方法章节
- 结果章节
- 局限性章节
- 结论章节

每章都必须回答两个问题：

1. 这一章是否直接回应了题目要求？
2. 这一章的结论是否有图表或统计结果支撑？

## 3.3 术语统一任务

C 必须统一全篇术语，推荐保留：

- 个体初值
- 类型平均衰减函数
- 动态阈值
- 反推初值
- 三区域判定
- 门槛型环境交互项

C 必须避免或删除：

- 统一退化机制
- 做功强度
- 证据寿命（独立概念化表达）
- 过强机理语言

---

## 4. 图表层任务细化

## 4.1 图表主责

本项目图表由 C 负责最终制作和交付。B 只负责提供：

- 图表源数据
- 绘图脚本
- 图表标题建议

C 负责将这些内容变成可直接入论文的图表成品。

## 4.2 必做图表清单

C 必须完成以下图表的最终出图、图注和插入：

1. 四类样品原始剩磁衰减曲线
2. 四类样品归一化曲线叠加图
3. `M0` 与 `M90/M0` 散点图
4. 公共平均衰减函数检验结果表
5. 含 / 不含交互项的 CV 误差对比图
6. 四类样品动态阈值曲线图
7. 反推初值区间宽度—延迟天数曲线图
8. 现场判定流程图

## 4.3 C 具体干什么

### 图表筛选

- 决定哪些图放正文
- 哪些图放附录
- 哪些图合并成多子图

### 图表绘制

- 根据 B 的源数据或脚本生成最终图
- 统一字体、线型、颜色、图例、坐标轴格式
- 统一图片尺寸和分辨率

### 图注撰写

每张图必须写图注，图注不能只描述“画了什么”，必须说明“图证明了什么”。

### 图表嵌入

- 安排图表在论文中的位置
- 确保图前有引入，图后有解释

## 4.4 图表质量标准

C 必须保证：

- 一张图只表达一个核心信息
- 图与正文数字一致
- 图中术语和正文术语一致
- 图注不夸大结论

## 5. 问题 1-4 的论文写作任务

## 5.1 问题 1

C 具体负责：

- 写初值双层表达
- 写初值相关性检验的稳妥结论
- 写共享平均衰减函数合理性的结论
- 写 23-29 天预测的统一模型来源说明

## 5.2 问题 2

C 具体负责：

- 先写标准统计归因
- 再写门槛交互的工程意义
- 明确区分“显著性结果”和“误差改善结果”
- 避免把问题 2 写偏成纯模型比赛

## 5.3 问题 3

C 具体负责：

- 写动态阈值公式
- 写 `1-90` 天阈值表说明
- 写“反推初值”作为补充解释
- 强调没有修改国标阈值，而是映射到观测时点

## 5.4 问题 4

C 具体负责：

- 写四步流程
- 写预处理模块
- 写三区域判定解释
- 写长延迟进入灰区的规则
- 写复检建议

---

## 6. 摘要、结论与创新点任务

## 6.1 摘要

C 负责写摘要，必须包含：

- 问题对象
- 模型主线
- 问题 1 预测
- 问题 2 统计分析
- 问题 3 动态阈值表
- 问题 4 三区域判定

## 6.2 结论

C 负责把结论压缩为：

- 主结构发现
- 关键统计结果
- 工程应用价值
- 使用边界

## 6.3 创新点

C 只能使用团队确认的四条创新点：

1. 识别并验证了“个体初值 × 类型平均衰减函数”的乘法结构；
2. 将国标静态阈值映射为观测时点的动态判定线，并给出 1-90 天阈值表；
3. 引入门槛型高温高湿交互项，并通过消融实验验证其对锈蚀钢筋预测的改善作用；
4. 构建了基于 block bootstrap 的三区域工程判定流程。

C 不得自行拔高创新点。

---

## 7. 边界声明与风险控制任务

C 必须把以下三句边界声明写进正文：

1. 本模型是基于实验数据与天气轨迹构建的经验衰减模型，而非完整磁畴微观机理模型。
2. 由于所有样品共享同一条天气轨迹，环境累计项主要用于描述该轨迹下衰减速度的经验修正，而不作严格独立因果解释。
3. 对长延迟、低剩磁及阈值附近样品，应采用三区域判定与复检建议，避免给出过度确定的结论。

C 还需检查全文是否有下列风险表述：

- 强机理包装
- 与题面不对齐
- 图表支撑不足
- 结论强于证据

C 需要从 A 获得：

1. 主模型最终版

4. 三区域规则最终版

C 需要从 B 获得：

1. 所有结果表格
2. 所有图表源数据
3. 所有绘图脚本
4. 每个数值的一句话解释
5. 图表标题建议

C 接到 B 的结果后，需完成：

- 图表成品制作
- 图表编号
- 图注撰写
- 图表嵌入论文

## 11. C 的最终交付物

1. 论文正文终稿
2. 全部图表成品
3. 图注与表注
4. 摘要、结论、创新点、局限性
5. 答辩提纲
6. 高风险问题回答清单

---

## 12. C 的禁止事项

1. 擅自更改数学定义
2. 为了文风美化而强化结论
3. 只插图不写解释
4. 图表和正文术语不一致
5. 创新点脱离数据支撑

---

## 13. C 的工作标准

C 最终必须达到的标准是：

- 论文结构清楚
- 图表完整专业
- 表述稳妥不夸大
- 图文一致
- 答辩口径统一

一句话总结：

> C 的任务不是“把内容写得更漂亮”，而是“把结果写成一篇评审愿意给分的论文，并把图表真正变成论文的证据系统”。
